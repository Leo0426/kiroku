# 工作流与交互第二批（2026-10-29）

本批在媒体库浏览能力之上增加 10 项功能，集中于批量管理、历史核对、待整理选择和可访问性。上一批的保存视图、最近搜索、列表视图、排序、随机选择、连续详情、完整性筛选、浏览恢复、快捷操作和 CSV 导出不重复计数。

| 功能 | 入口与行为 |
|---|---|
| 1. 批量收藏与取消收藏 | 媒体库工具 → 选择影片批量编辑。可跨页选择，每批最多 200 部；先预览，确认后逐片保存。无变化跳过。 |
| 2. 批量标签增删 | 同一批量编辑入口切换到标签增删。每行一个标签，完整文字匹配，保留其它标签；实际变化记为人工编辑并锁定标签字段。 |
| 3. 历史组合检索 | 按影片编号或日志编号、状态、本机日期范围检索。搜索覆盖每条日志全部影片编号，不限摘要展示的前六个；多个关键词同时匹配。结束日期包含当天。 |
| 4. 历史操作详情 | 展开记录，分页查看文件操作、修订、待核对操作和移到废纸篓的路径，每页 100 项。显示状态来自日志，不能替代当前磁盘检查。 |
| 5. 待整理预览检索与排序 | 按文件名、路径、编号、识别状态、来源筛选，按名称、编号或体积排序。明确限定本次已检查预览；未完成扫描不宣称已查遍来源。 |
| 6. 仅整理所选文件 | 勾选预览中的文件后只扫描这些文件，再进入原有刮削和整理预览。保存的来源目录不变；进行中的导入需先完成或重置。 |
| 7. 当前筛选概览 | 媒体库工具中统计全部匹配影片的数量、文件数、逻辑体积、收藏、平均评分与资料缺项。忽略分页偏移；逻辑体积来自索引，硬链接可能共享空间。 |
| 8. 连续键盘浏览 | 海报和列表支持方向键，Home / End 跳到整个查询首尾，Enter 打开详情。跨页先定位和加载，再聚焦；保留虚拟化和请求预算。 |
| 9. 设置项搜索定位 | 搜索设置名称和常用别名，点击结果或按 Enter 跳到分类和控件。跳转保留未保存草稿；不检索设置中的凭据或私人路径。 |
| 10. 外观偏好 | 设置 → 常规：系统/浅色/深色，100%/115%/130% 文字，跟随系统/减少动态效果。立即生效并保存在本机，与业务设置分开。 |

## 调研依据与取舍

- [Plex Library View](https://support.plex.tv/articles/200392126-using-the-library-view/) 与 [Edit Details](https://support.plex.tv/articles/201272763-edit-details/) 的多项编辑和人工锁定，是批量操作与标签差异的参考。实现沿用本项目修订日志，不引入跨影片原子事务。
- [Apple Console 检索](https://support.apple.com/en-ae/guide/console/cnslbf30b61a/mac) 与 [日志详情](https://support.apple.com/guide/console/log-messages-cnsl1012/mac/) 支持将“找到记录”和“解释操作”作为两个独立任务。编号、状态和日期是本项目的领域适配。
- [Apple 多项选择](https://support.apple.com/en-sg/guide/mac-help/mchlp1378/27/mac/27)、[tinyMediaManager 筛选](https://www.tinymediamanager.org/docs/movies/filters) 支持先缩小范围再执行。本项目将待整理筛选明确限制在有界预览，保留完整来源扫描入口。
- [WAI 键盘界面](https://www.w3.org/WAI/ARIA/apg/practices/keyboard-interface/) 和 [Grid Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/grid/) 用于区分焦点与选择。这里保留按钮和区域语义，不在缺少行列结构时声明 ARIA grid。
- [VS Code 设置搜索](https://code.visualstudio.com/docs/configure/settings)、[主题](https://code.visualstudio.com/docs/configure/themes) 与 [W3C 交互动画](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html) 是设置发现和外观控制的参考。

Plex 页面直接读取返回 403，调研采用同一官方 URL 的搜索索引正文。上述资料用于工作流参考，不代表本项目做过用户频率调查。概览的指标组合是根据现有 SQLite 投影作出的工程选择。

## 实现约束

- 收藏与标签复用服务端持有的批量修订预览，但拥有独立于单片编辑和语言导出的预览槽。token 绑定库根、根身份和设置；写入前复核每片目录与内容。一次任务逐片落盘，部分失败或取消保留已完成日志。索引仍只通过 `Library::reindex_dir` 更新。批量预览响应只包含编号、差异与警告；关闭、返回选择、卸载、失败或迟到取消时按 token 释放后端资源，旧 token 不删除新预览。
- 标签单次最多添加/移除各 50 项，单项不超过 200 UTF-8 字节；去除首尾空白、合并重复项，拒绝同时增删同一标签。相同标签集不增加人工锁定或修订日志。
- 历史筛选需要检查全部日志的匹配信息，支持取消并复用有界缓存。默认无条件浏览仍只解码当前页。详情不发送 NFO/sidecar 正文、下载 URL、备份证明或恢复凭据；实际撤销继续执行原有磁盘验证。
- 媒体库概览和列表共用 SQL 条件，运行在只读快照中，不拉取所有卡片到前端求和。迟到的查询结果不覆盖新筛选。概览请求跨组件生命周期共用一个并发槽，已过期的排队查询立即结束并释放队列引用，已派发请求占槽到真实返回；搜索只在防抖后的查询值改变时派发。
- 外观采用 WebView 本地偏好，损坏数据回退默认，写入失败提示。减少动态效果同时作用于 CSS 和 Svelte 动画；文字尺寸参与虚拟行高计算。
- 新工具栏可折行，历史详情和批量选择区有独立滚动范围，设置搜索结果收起后将焦点交还实际控件。

## 验证

- `cargo test`：573 项通过、21 项按仓库现有配置忽略。新增核心回归覆盖完整编号检索、历史详情分页与正文隔离、查询聚合、标签语义、实际修订和撤销。
- 浏览器完整回归：313 项通过。随后收尾的慢查询、无效日期忙碌状态与键盘刷新处理通过 28 项相关回归；键盘时序问题另连续复测 10 次通过。新增两条慢请求用例包含在这 28 项中，未将它们计入此前的 313 项全量结果。
- `pnpm check`：0 错误、0 警告；`pnpm build`、`cargo check -p kiroku-desktop`、`git diff --check` 通过。
- 窄窗口与截图检查覆盖 390、720、960 像素宽度和 130% 文字，批量工具及待整理控件无横向溢出，浅深色和减少动态效果正常。

测试使用合成媒体和临时库；没有对真实媒体执行整理或修改。完整原生 WebKit 交互与 Windows 实机验收不在本轮自动化覆盖内。

性能优化后的验证与资源边界见 [2026-10-29 性能审查](performance-review-2026-10-29.md)。
