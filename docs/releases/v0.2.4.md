本次发布汇总 v0.2.0 之后的版本标记、人工编辑和详情布局改进，并重写使用文档。

## 新增与改进

- 识别 `-LTX` 文件名后缀为破解版本，支持字幕、分片组合，并防止较长后缀或编号前缀误匹配。默认整理为 `-U` 或 `-UC`。
- 编辑元数据时可手动修订版本标记和清晰度；支持差异预览、保存及历史撤销。
- 有可验证原图和裁剪范围时同步重绘海报；无原图或范围不明时明确提示，保留原海报。背景图不重绘。
- 详情面板支持拖动调整宽度、记忆宽度、双击复位及键盘操作，窄窗口自动适配。
- 统一主操作和工具按钮布局，改善编辑区对齐、标签间距与区块留白。
- 修复整理尚无结果时出现空白卡片的问题。
- README 补充安装、首次使用、主要功能、数据与撤销边界，以及开发流程。

## 安装与兼容性

- macOS Apple Silicon 使用 `aarch64.dmg`，Intel 使用 `x64.dmg`；Windows x64 使用 `.exe` 或 `.msi`。
- 安装包未配置 Developer ID 公证或 Windows 代码签名。
- 相比 v0.2.0 无新增配置迁移；影片修订仍通过原有日志保存与撤销，不改名视频。旧版本读取新增标记后不会自动回填文件名。
- 回退可重新安装上一发布版；撤销人工修订请使用历史，不通过降级应用恢复媒体文件。
- Windows 文件系统语义仍有已知适配限制，详见路线图。
