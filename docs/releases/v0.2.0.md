媒体库浏览与批量管理更新，包含任务取消、内存占用和界面排版修复。

## 新增与改进

- 媒体库支持保存筛选视图、最近搜索、列表视图、海报密度、双向排序、完整性筛选、筛选内随机挑选、连续详情浏览和 CSV 导出。
- 新增批量收藏及标签增删，最多选择 200 部，先预览变化再逐片保存；历史支持编号、状态、日期检索及操作详情。
- 待整理预览支持搜索、筛选、排序和仅导入所选文件；媒体库工具新增当前筛选概览。
- 新增全局快捷操作、键盘浏览、设置搜索、浅深色主题、文字大小及减少动态效果偏好。
- AI 汉化支持多个 Provider 配置，可选择 Anthropic Messages 或 OpenAI Chat Completions 兼容服务，并试译未保存配置。
- 刷新媒体库时检查已移走的影片，只清理索引记录；失效来源显示原因并提供移除入口。

## 修复与性能

- 修复任务取消和退出应用时的状态清理，提高整理流程可靠性。
- 关闭或取消批量预览后释放后台资源，缩小预览响应，减少重复查询及取消队列占用。
- 优化大库反向排序和分批检查；保留磁盘校验、逐片日志和回滚机制。
- 修复失效来源提示的图标、文字和按钮错位，支持长路径换行及大字号。

## 安装与兼容性

- macOS Apple Silicon 请选择 `aarch64.dmg`，Intel 请选择 `x64.dmg`；Windows x64 提供 `.exe` 和 `.msi`。
- 安装包未配置 Developer ID 公证或 Windows 代码签名，系统可能显示未知开发者提示。
- 升级前备份系统配置目录中的 `kiroku/settings.json`。旧 AI 配置在读取时迁移，保存后采用新结构；退回 v0.1.0 时需恢复升级前的设置备份。
- 媒体库 SQLite 缓存升级至 v5，首次打开旧库会增加排序索引。NFO、sidecar 和媒体文件仍是数据来源，索引可重建。
- 回退时先退出应用，安装 [v0.1.0](https://github.com/Leo0426/kiroku/releases/tag/v0.1.0) 并恢复设置；缓存异常可从磁盘重建索引。整理或编辑操作的撤销请使用历史记录。
- 本轮已通过 Rust、浏览器回归和 macOS 原生 WebKit 启动验证；Windows 实机交互、网络盘与长时间运行仍需后续验证。
