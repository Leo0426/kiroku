新增人工版本标记编辑，并修复整理中的空白卡片。

## 变化

- 影片详情的编辑元数据面板可手动修改字幕、无码、破解（含 LTX）、流出和清晰度标记。
- 版本标记与普通分类标签独立；支持差异预览、保存和历史撤销。
- 有保留原图且裁剪范围可确认时重绘海报；缺少原图或无法确认裁剪范围时保留原海报并提示。背景图不重绘。
- 整理期间尚无文件完成时不再显示空白结果卡片。

## 兼容性与回退

- 不重命名视频或移动媒体，无新增配置迁移。
- 本地安装前备份当前应用与设置；回退时退出应用并恢复备份。人工编辑通过历史撤销。
- macOS Apple Silicon 本地 ad-hoc 签名，未配置 Developer ID 公证。
