# ADR-0003：已有影片追加与保守库维护

状态：已采纳（2026-10-08）。

## 决策

- 追加通过磁盘元数据定位已有目录；同号多目录不猜测。预览由后端持有，执行前复核根、元数据和源文件；同内容重复保留源，异内容拒绝。既有 NFO、sidecar、海报和归档位置不改；新增文件复用 ADR-0002 的可撤销发布。
- 来源自检复用各来源端点、网络栈与错误分类，支持单站重试；可达不等于影片命中或登录成功。
- 健康检查与维护预览只读，SQLite 不在扫描中重建。库根缺失或身份变化报错，不当空库或创建影子库；明确新建库才允许 `--create-library`。修复索引仍只走 `Library::reindex_dir`。
- 维护仅候选无引用原图、完整撤销且无依赖的历史与备份、非当日日志。有效、部分或待恢复记录及跨日志锚保留；损坏或未知数据不能证明资源可回收。默认保留期 90 天只影响候选，不自动使有效撤销失效。
- 执行前复核路径、身份、摘要和引用，送系统废纸篓，历史 JSON 最后移动。失败允许部分完成，重新预览处理剩余项；应用不提供维护撤销。

## 边界

库内 symlink 和越界仍拒绝；容量按逻辑文件长度统计，不承诺硬链接的物理回收量。预览与文件 I/O 可取消并在后台执行；真实异卷、网络盘、断电、Windows 和原生 GUI 尚需各自验证。
