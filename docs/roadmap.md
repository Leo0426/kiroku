新增来源默认禁用；部分来源只有有限的正向验证，或因站点限制（403、526 等）尚无正常页验收，诊断结果不视为未命中。缓存无 TTL；更换登录/代理配置身份会使对应快照失效，需要新鲜内容时显式强制刷新。元数据更新不重命名视频，Plex 不因 NFO 标题修改而自动改影片标题。

验证范围为临时目录中的真实 core 文件操作、浏览器 mock 界面及上述 macOS 原生退出、命令取消和共享前端模块的 WebKit 桥接工具；完整原生组件交互、Windows、真实媒体与真实废纸篓尚未实机验收。v3 更新已有 v2 产物时捕获严格校验的原 inode 所有权锚，正常逆序撤销可继续撤 v2；锚或备份丢失/被替换/篡改时拒绝恢复并保留资产。旧无锚日志仍按原恢复规则处理。备份保留，多文件修订并非原子事务；实际异卷、网络盘、断电、跨进程最终校验竞态与 ACL/xattr 仍未验。
