个人日常稳定使用路线：

1. 已完成：全部产物冲突与无覆盖提交、逐操作可恢复日志、重建/任务真实状态。
2. 已完成：仅失败条目重试、候选图片验证和回退、库内补缺图（包括根目录 NFO-only 条目）。
3. 已完成：十字段可撤销修订、来源展示与重选、锁定空值、所选字段原位重刮、逐站原始结果缓存、保留原图的连续海报裁剪。
4. 已实现：已有影片安全追加、来源自检、只读库健康报告与空间维护；设计边界见 [ADR-0003](adr/0003-library-maintenance.md)。
5. 已实现：拖拽导入（文件夹与单个视频）、历史分页、按站点代理、按详情页地址刮削、同编号不同影片的日期核对、外挂字幕判定、AI 译文缓存、海报墙多维筛选与收藏、单部影片跨站并发与站点暂停。
6. 已实现：任务完成系统通知、内置标签译名（并入名称规则）、经用户自行运行的 FlareSolverr 访问被 Cloudflare 拦住的站点（[ADR-0007](adr/0007-external-challenge-solver.md)）、按详情页地址刮削。同一影片内合并日志边界（ADR-0006 修订），整理快约 25%。
7. 已实现：标题剔除演员名（[ADR-0011](adr/0011-title-actor-strip.md)）、NFO 演员头像（[ADR-0009](adr/0009-actor-thumbs.md)）、Jellyfin/Emby 整理后刷新（[ADR-0010](adr/0010-jellyfin-emby-refresh.md)）、同编号新版本并存（[ADR-0008](adr/0008-same-code-versions.md)，替换旧版本暂缓）。真实 Jellyfin/Emby/Kodi 尚未实测。

可靠性决策见 [ADR-0002](adr/0002-durable-organize-journal.md)。

新增来源默认禁用；部分来源只有有限的正向验证，或因站点限制（403、526 等）尚无正常页验收，诊断结果不视为未命中。缓存无 TTL；更换登录/代理配置身份会使对应快照失效，需要新鲜内容时显式强制刷新。元数据更新不重命名视频，Plex 不因 NFO 标题修改而自动改影片标题。

验证范围为临时目录中的真实 core 文件操作和浏览器 mock 界面，未作原生 Tauri/Windows/真实媒体与真实废纸篓实机验收。v3 更新已有 v2 产物时捕获严格校验的原 inode 所有权锚，正常逆序撤销可继续撤 v2；锚或备份丢失/被替换/篡改时拒绝恢复并保留资产。旧无锚日志仍按原恢复规则处理。备份保留，多文件修订并非原子事务；实际异卷、网络盘、断电、跨进程最终校验竞态与 ACL/xattr 仍未验。

后置：更多数据源与目录、Windows 实机验收与签名。已有双平台 CI 配置不等于 Windows 发布验收完成。

Windows 测试现状（2026-10-17）：CI 上 Windows 能编译并打出安装包，但 core 的单元测试与约 12 个集成测试目标仍有失败，集中在硬链接、改名覆盖、日志恢复与海报原图等文件系统语义上；CI 对 Windows 测试暂不阻断，失败详情见检查结果的注解。

Windows 优先级（2026-10-07）：Windows 实机、兼容专项与签名排在全部日常可靠性及修订功能之后，优先级最低；以 macOS 开发和验证为主，保留双平台构建配置。
