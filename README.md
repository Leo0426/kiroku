# kiroku

自用，勿传播...

## 功能

- **导入整理**：扫描文件夹 → 获取元数据 → 预览计划（冲突默认跳过）→ 执行；支持移动、复制、硬链接、软链接。
- **媒体库**：海报墙搜索、筛选、收藏；详情编辑与重新获取；追加视频或字幕；库健康检查。

- **元数据源**：多个可选来源，支持按来源配置代理、Cookie 与字段优先级。
- **其他**：命名模板、封面裁剪、字幕随迁、AI 翻译（自备 Anthropic API Key）、Plex / Jellyfin / Emby 刷新。
